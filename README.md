# Course-Selling-App

This Course Selling App is a Backend only project created using nodejs

This backend has 2 roles : User and Admin

User can signup, login, view available courses to buy, purchase a course and view his purchased courses <br>
Admin can signup, login, create a course, update a course, delete a course and view his courses
